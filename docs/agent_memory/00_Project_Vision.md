# RI.UVT.RO — Project Vision

Headless WordPress + React redesign platform for the International Relations Department of UVT.

## Core Goals
- Improve user clarity
- Rebuild information architecture
- Replace document-heavy workflows
- Establish scalable frontend/backend architecture
- Support multilingual delivery
- Improve accessibility and maintainability

## Core Stack
- WordPress (Headless CMS)
- REST API
- React / Next.js frontend
- TypeScript
- Tailwind CSS

## Main User Types
- Incoming Erasmus students
- Outgoing students
- International applicants
- Academic staff
- Partner institutions
- Internal editors/admins

## Architectural Direction
WordPress CMS → REST API → React Frontend → User Experience

## Philosophy
- Systems over pages
- Audience-first navigation
- Guided journeys
- Reusable components
- Structured content models
