\section{Week 3 Carry-Overs --- Priority Zero}

% ----------------------------------------------------------
\subsection{Design System Draft Document}
% ----------------------------------------------------------

\textbf{File:} \texttt{docs/design-system-draft.md}

Formalise the visual language of the platform using existing tokens as source of truth.

\vspace{0.8em}
\noindent\textbf{Colors to document:}

\begin{itemize}
    \item Primary: \texttt{uvt-blue: \#005BBB} --- main brand, interactive elements, links
    \item Deep: \texttt{uvt-navy: \#002147} --- backgrounds, footer, dark sections
    \item Accent: \texttt{uvt-gold: \#F2B705} --- secondary CTA, highlights, badges
    \item Background: \texttt{uvt-gray: \#F5F5F5} --- page backgrounds, card backgrounds
    \item Usage rules: when to use each color, what is never allowed (e.g. gold text on white --- contrast check required)
\end{itemize}

\vspace{0.8em}
\noindent\textbf{Typography to document:}

\begin{itemize}
    \item Font family: specify the font stack (Tailwind default or custom)
    \item Heading scale: h1 (\texttt{text-5xl} = 48px), h2 (\texttt{text-4xl} = 36px), h3 (\texttt{text-2xl} = 24px)
    \item Body: \texttt{text-base} = 16px, line-height 1.75
    \item Caption: \texttt{text-sm} = 14px, color gray-500
    \item Button text: \texttt{text-sm} (sm), \texttt{text-base} (md), \texttt{text-lg} (lg)
    \item Heading weight: 700, letter-spacing: -0.02em
\end{itemize}

\vspace{0.8em}
\noindent\textbf{Spacing to document:}

\begin{itemize}
    \item Section padding: \texttt{6rem} (96px) vertical
    \item Container max-width: \texttt{1280px}
    \item Card spacing: document the padding used across Card, AccordionSection, PageLayout
    \item Grid gap: document the gap value used in ContentGrid
\end{itemize}

\vspace{0.8em}
\noindent\textbf{Additional:}

\begin{itemize}
    \item Elevation / shadow: document any box-shadow usage or lack thereof
    \item Border radius: specify standard values (\texttt{rounded-xl} on cards and accordions --- confirm rule)
\end{itemize}

% ----------------------------------------------------------
\subsection{Typography, Spacing, and Color Rules Document}
% ----------------------------------------------------------

\textbf{File:} \texttt{docs/typography-spacing-color-rules.md}

A concise reference card formatted as tables, not a narrative. Cover:

\begin{itemize}
    \item Heading scale with pixel values, Tailwind class, and usage context
    \item Paragraph line-height values per context
    \item Link styles (default, hover, visited, focus)
    \item Button text sizing per button size
    \item Section padding values (desktop, tablet, mobile)
    \item Card internal padding
    \item Grid gap values per grid type
    \item Mobile overrides (which spacing values change below \texttt{md:} breakpoint)
    \item Color usage table: color name \textrightarrow{} hex \textrightarrow{} use case \textrightarrow{} forbidden use
\end{itemize}

This is the reference Role 5 and Role 4 use when building new components to ensure visual
consistency.

\subsection{Core Wireframes Notes}
% ----------------------------------------------------------

\textbf{File:} \texttt{docs/core-wireframes-notes.md}

Produce wireframe descriptions (text or annotated sketches) for each layout type below.
These do not need to be polished --- they must specify component composition and content hierarchy.

\vspace{0.8em}
\noindent\textbf{Homepage:}
Navbar at top \textrightarrow{} HeroSection with audience-oriented CTAs \textrightarrow{} Featured content sections (news, open calls, key programmes) \textrightarrow{} Footer.

\vspace{0.8em}
\noindent\textbf{Internal section page} (e.g. Erasmus overview, About):
Navbar \textrightarrow{} Page title + breadcrumb \textrightarrow{} Body content (static WP Page content) \textrightarrow{} Optional sidebar or CTA block \textrightarrow{} Footer.

\vspace{0.8em}
\noindent\textbf{Listing page} (Programmes / Calls / Resources):
Navbar \textrightarrow{} SectionHeader with title and optional filter \textrightarrow{} ContentGrid of Cards \textrightarrow{} Footer.

\vspace{0.8em}
\noindent\textbf{Detail page} (single Programme / single Call):
Navbar \textrightarrow{} Page title + metadata (deadline, language, ACF fields) \textrightarrow{} Body content \textrightarrow{} Structured sections (AccordionSection for application steps, DocumentDownloadList) \textrightarrow{} Footer.

\vspace{0.8em}
\noindent\textbf{Contact page:}
Navbar \textrightarrow{} Contact card(s) \textrightarrow{} Form or CTA \textrightarrow{} Footer.

\subsection{Accessibility-Friendly Visual Patterns}
% ----------------------------------------------------------

\begin{itemize}
    \item[\faAdjust] Visible focus states --- Button has \texttt{focus:ring-2 focus:ring-uvt-blue}. Check Navbar links, Footer links, AccordionSection trigger, and TabsSection tabs --- all interactive elements must have a visible focus indicator.
    \item[$\square$] Contrast check --- \texttt{uvt-blue \#005BBB} on white: WCAG AA requires 4.5:1 for normal text. Verify. \texttt{uvt-gold \#F2B705} on white likely fails --- document and restrict to large text or decorative use only.
    \item[\faAdjust] Hover states --- Navbar and Footer links have hover; check all interactive elements
    \item[$\square$] Active states --- Button has no explicit active style; add \texttt{active:} class
    \item[$\square$] Confirm \texttt{aria-expanded} on AccordionSection is correct
    \item[$\square$] WCAG 2.1 AA compliance --- document target in \texttt{accessibility-implementation-standards.md} (co-authored with Role 1)
\end{itemize}
