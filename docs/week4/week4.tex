\subsection{3. Implementation Sequencing Rule}\label{implementation-sequencing-rule}

The implementation order must remain system-first, not page-first.

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  \textbf{Design tokens} before visual components.
\item
  \textbf{Atoms} before molecules.
\item
  \textbf{Molecules} before organisms.
\item
  \textbf{Templates} before full pages.
\item
  \textbf{API helpers} before page-level data usage.
\item
  \textbf{Content model} before final frontend integration.
\end{enumerate}

This prevents the team from creating isolated one-off pages that cannot be reused later.
