\subsection{Missing Organism: DocumentDownloadList}

\textbf{File:} \texttt{organisms/DocumentDownloadList/DocumentDownloadList.tsx}

Required for resource pages and call pages where users need to download forms and documents.

\begin{itemize}
    \item[$\square$] Props: \texttt{documents: Array<\{ label: string; url: string; fileType?: string \}>}
    \item[$\square$] Renders a list of download links with a file type indicator (PDF, DOCX, etc.)
    \item[$\square$] Each link must open in a new tab and have a clear download affordance
    \item[$\square$] Must be accessible: descriptive link text, not just ``Download''
    \item[$\square$] Will be connected to the \texttt{documents} ACF field on the \texttt{call} CPT and \texttt{file\_url} on the \texttt{resource} CPT
\end{itemize}
