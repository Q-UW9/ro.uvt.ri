# WordPress CPT and Taxonomy Mappings
System relationships established for granular client querying.

### Custom Taxonomies Registered:
1. **Audience (`audience`):** Applied to calls, programmes, stories to filter targets (e.g., outgoing students, incoming staff).
2. **Programme Family (`programme-family`):** Categorizes frameworks like Erasmus+ vs CEEPUS.
3. **Content Topic (`content-topic`):** Filters resources or stories by administrative types.
4. **Academic Year (`academic-year`):** Controls timeline groupings for historical indexing.
