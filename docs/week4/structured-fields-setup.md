# Structured Fields Configuration Schema
Exposing contextual endpoints to optimize client-side runtime sorting/filtering parameters.

- **Calls:** `application_deadline` (Date Picker), `financial_support` (Text).
- **Programmes:** `country` (Text), `coordinator_email` (Email).
- **Resources:** `download_url` (URL), `document_type` (Select component dropdown).
- **Stories:** `testimonial_author` (Text), `study_destination` (Text).
