\texttt{\#003B71} (primary), \texttt{\#F2C94C} (secondary),
\texttt{\#00A86B} (accent). The main branch \texttt{index.css} already
has \texttt{uvt-blue:\ \#005BBB}, \texttt{uvt-navy:\ \#002147},

built every component against the main branch tokens. Role 4's color

must be resolved before any visual QA can be done: either Role 4 adopts
the existing tokens or a formal decision is made to replace them.
