\subsection{Architecture Rules Enforced}

\begin{itemize}
    \item No API calls inside components --- all fetching stays in
          \path{src/api/wordpress.js}.
    \item No routing inside templates or organisms.
    \item Templates compose organisms; organisms do not compose templates.
    \item Page files own data fetching and pass data down as props.
    \item Tailwind utility classes only --- no per-component \texttt{.css}
          files.
\end{itemize}
