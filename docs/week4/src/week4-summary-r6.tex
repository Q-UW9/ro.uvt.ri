\subsection{ACF Field Groups Created}

4 field groups created with \texttt{show\_in\_rest: 1}, one per CPT.
ACF Local JSON sync folder (\path{acf-json/}) placed in the correct
theme location.

\begin{itemize}
    \item \textbf{Calls} --- deadline, eligibility, application steps,
          documents, funding details.
    \item \textbf{Programme Details} --- title, duration, language,
          partner institution, application deadline.
    \item \textbf{Resource Details} --- file URL, file type, audience,
          audience notes.
    \item \textbf{Story Details} --- author, programme, story date,
          pull quote, image.
\end{itemize}
